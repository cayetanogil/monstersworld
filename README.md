# Monster Map Challenge

A small daily geo-guessing game where a monster appears somewhere in the world and you have to figure out **where**.  

It’s a map-based guessing game built with modern React/Next.js, using Leaflet for maps, Convex for backend data, and Clerk for authentication.

**Live demo:** https://monstersworld.vercel.app

## Features

- **Daily challenge** – A new monster + landmark combo every day.
- **Interactive map** – Click on the world map to place your guess.
- **Scoring system** – The closer your guess is to the real location, the higher your score.
- **Authentication & persistence** – Backed by Convex and Clerk so game data and users can be persisted when configured.

---

## Tech Stack

- **Framework:** Next.js (React + TypeScript)
- **Mapping:** Leaflet
- **Styling and UI:** Tailwind CSS / Headless UI
- **Backend & data:** Convex
- **Auth:** Clerk
- **Tooling:** ESLint, Prettier
